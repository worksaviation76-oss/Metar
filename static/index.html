This is the manual-input counterpart of the full auto-fetching version (Python/FastAPI backend, deployed on Render). Same rule engine and citations, ported to JavaScript so it can run on GitHub Pages with no server. Rules cover: wind, visibility, temperature/dewpoint, QNH, cloud, gust logic, and CAVOK exclusivity — per ICAO Annex 3 App.3 / WMO No. 782. Not yet covering RVR tendency, trend groups, or the full present-weather combination table.
